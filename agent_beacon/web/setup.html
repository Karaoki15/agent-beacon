01

Якими агентами користуєтеся?

Beacon додає обробники подій — хуки. Вони повідомляють про роботу, питання та завершення. Тексти ваших розмов не передаються.

Вхід в облікові записи й довіра до проєктів залишаються у самих агентах. Звичайний Claude Chat, хмарні, SSH та WSL-сесії цим локальним підключенням не охоплюються.

02

Налаштуйте одним натисканням

Спочатку покажемо файли, яких стосується зміна. Інші хуки зберігаються, перед зміною створюються резервні копії.

Буде змінено

    Файли й резервні копії

      Вимкнений агент перестає відстежуватися цією копією Beacon; його старі хуки не видаляються. При зміні вибору програма коротко перепідключиться.

      Якщо зміну заблоковано, відкрийте «Допомогти підключити» в картці агента: там готовий промпт для Codex або Claude Code. Він не містить ключів чи даних чатів.

      03

      Телефон — один раз

      Комп’ютер і Android мають бути в одній довіреній мережі. Спершу встановіть APK, потім відскануйте окремий QR підключення всередині застосунку.

      Увімкніть доступ для телефона й застосуйте налаштування вище.

      Завантажити APK
      Телефон не бачить комп’ютер?

      Вимкніть гостьову Wi-Fi мережу та VPN для перевірки. Профіль мережі у Windows має бути «Приватна». Дозвіл нижче стосується тільки Beacon, приватного профілю й локальної підмережі.

      Windows запитає дозвіл адміністратора. Ця дія сама не змінює профіль вашої мережі.

      Після першого підключення використовуйте Check & connect на телефоні. Повторний QR зазвичай не потрібен. iPhone поки не підтримується в цій беті.
