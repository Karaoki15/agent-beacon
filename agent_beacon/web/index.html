ВАШІ АГЕНТИ

Поточні чати

оновлюються автоматично

Великою назвою показано чат, нижче — його проєкт і агент. Готові чати залишаються тут 30 хвилин і повертаються при новій роботі. Попередження про втрачений стан залишаються видимими.

Зараз немає поточних чатів. Новий запит автоматично поверне чат у цей список.

Як відстежувати Claude у застосунку?

Вкладка Code, локальні чати. Загальні обробники Beacon підключаються один раз для вашого користувача. Після цього відкрийте новий чат у вкладці Code, виберіть Local та потрібний проєкт. Запуск через окремий скрипт більше не обов’язковий.

Команда одноразового підключення з папки Agent Beacon:

python -m agent_beacon.adapters.configure claude --install --scope user --state-dir .beacon --apply

На цьому ПК загальне підключення вже налаштоване. Інші налаштування Claude зберігаються; перед зміною створюється резервна копія. Уже відкриті чати можуть потребувати нового запуску, щоб завантажити обробники.

Звичайна вкладка Chat поки не відстежується. Вона не використовує обробники Claude Code. Хмарні, SSH та WSL-чати також потребують підключення у своєму середовищі.

Для окремого запуску в терміналі залишається доступним скрипт:

.\scripts\windows\Start-ClaudeWithBeacon.ps1 -ProjectPath 'H:\мій-проєкт'
Останні зміни стану до 30 подій

Історія починається заново після перезапуску сервера. Тексти запитів і відповідей не зберігаються.

Перевіряємо, чи доступна локальна мережа…

Підключіть телефон один раз. У версії Android 0.1.7 він сам знаходить раніше підключений Beacon після перезапуску або зміни адреси. QR потрібен для першого підключення; залиште фоновий моніторинг увімкненим.

Відскануйте камерою телефона в тій самій Wi‑Fi мережі.

QR завантаження відкриває APK за адресою локальної мережі. Або завантажте APK на комп’ютері та передайте його телефоном через USB.

QR-код одноразовий і діє 2 хвилини.
