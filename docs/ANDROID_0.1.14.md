# Android 0.1.14 / code 15

Додано українську й англійську мови для головного екрана, підключення, помилок, історії, діагностики, налаштувань віджетів і сповіщень. У нижній частині головного екрана — «Мова застосунку / App language»: Автоматично, Українська, English.

Автоматично англійська обирається лише для англійської мови телефона; усі інші мови використовують українську. Явний вибір зберігається в окремих налаштуваннях оформлення. Підключення й ключі Android Keystore не змінюються. Екрани перебудовуються після зміни мови; поточні сповіщення оновлюються тихо, без повторного приймання подій, зі збереженням решти часу їхньої дії. Налаштування гучності та важливості існуючих каналів зберігаються.

Короткі написи компактного й великого віджетів залишаються англійською. Імена користувацьких чатів/проєктів не перекладаються; перекладаються лише службові підписи й порожні назви. Протокольні стани й агрегація агентів не змінені.

Кнопки отримали спільний native-стиль: заокруглені краї, рамки, м’ятний основний акцент, ripple і читабельний неактивний стан. Довгі написи використовують гнучку висоту. Основний фон і картки — нейтрально чорні/сірі. Переклади зберігаються в tools/translations.json, стандартні ресурси values та values-en генеруються tools/generate_translations.py.

Оновлення встановлюється поверх попереднього APK зі збереженням чинного debug-сертифіката. Власний ключ цього робочого каталогу не публікується; інший checkout для розробки використовує окремий стандартний debug-ключ.

Виконуються offline lint/assemble, перевірка DEX і v2 підпису, 60 перевірок мовної політики, перевірка парності ресурсів та регресії станів/віджетів. Браузерні UK/EN/1.4× макети — лише попередній перегляд, не Android framework rendering. На фізичному телефоні ще потрібно перевірити перемикач під час моніторингу, перезапуск, мовні налаштування ОС, системні дозволи, обидві мови та великий шрифт.
