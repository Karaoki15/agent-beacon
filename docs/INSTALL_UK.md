# Встановлення Agent Beacon

**Українська** · [English](INSTALL_EN.md)

Версії: Windows **0.2.0-beta.4**, Android **0.1.15**. Потрібні Windows x64 та Android 8 або новіший. На комп’ютері вже має бути встановлений і авторизований підтримуваний агент.

## 1. Завантаження на комп’ютер

Відкрийте https://github.com/Karaoki15/agent-beacon і натисніть **Завантажити для Windows — EXE**. Або відкрийте розділ Releases → v0.2.0-beta.4 → Assets → AgentBeacon-Setup.exe.

Завантаження доступне без акаунта GitHub. Git, GitHub Desktop, Python і папка вихідного коду не потрібні. Не вибирайте автоматичний Source code ZIP, якщо просто хочете встановити програму.

Для іншого ноутбука завантажте EXE безпосередньо на ньому або перенесіть файл флешкою. Приватні каталоги даних і токени зі старого ПК переносити не потрібно.

## 2. Встановлення Windows

Запустіть AgentBeacon-Setup.exe від свого звичайного користувача, виберіть ярлик і натисніть **Встановити й відкрити**. Інсталятор містить потрібний runtime, створює ярлики й запис для видалення. Усе встановлюється для поточного користувача.

Програма: %LOCALAPPDATA%\Programs\AgentBeacon

Налаштування й підключення: %LOCALAPPDATA%\AgentBeacon

Поточна бета не має Authenticode-підпису; системне попередження можливе. Перевірте походження файлу та SHA256SUMS.txt із релізу. Не вимикайте захист Windows, щоб запустити неперевірений файл.

## 3. Підключення агентів

У браузері відкриється локальний майстер. Виберіть Codex, Claude Code та/або Antigravity. Натисніть **Переглянути зміни**, прочитайте план, потім **Підключити вибраних агентів**.

Хуки — це команди, якими агент повідомляє Beacon про початок роботи, питання й завершення запиту. Інсталятор не додає їх без цього кроку. Попередні налаштування резервуються, сторонні хуки зберігаються.

Перезапустіть агента або відкрийте новий локальний чат, дайте коротке завдання й натисніть **Перевірити підключення**. «Хуки записано» ще не означає отриману подію: потрібен реальний сигнал від агента.

Якщо налаштування заблоковане, кнопка **Допомогти підключити** дає готовий промпт для агента з правильною командою саме на цьому ПК. Авторизація та довіра до папки налаштовуються в самому агенті. Звичайний Claude Chat, хмарні й SSH/WSL-сесії цією бетою не охоплюються. Antigravity поки експериментальний.

## 4. Android: спочатку встановлення, потім підключення

У майстрі Windows увімкніть доступ для телефона. Комп’ютер і телефон мають бути в одній довіреній мережі.

1. **QR встановлення APK** скануйте звичайною камерою телефона. Або відкрийте GitHub Releases на телефоні й виберіть AgentBeacon-Android.apk.
2. Встановіть APK. За потреби самостійно надайте Android дозвіл для встановлення з обраного джерела. Поточна APK-збірка підписана debug-сертифікатом.
3. Створіть у майстрі **окремий QR підключення**. У застосунку Android натисніть «Сканувати QR підключення» / Scan pairing QR і відскануйте його, потім «Підключити» / Connect.
4. Код одноразовий і чинний дві хвилини. Якщо прострочився, створіть новий.
5. Дозвольте сповіщення й увімкніть фоновий моніторинг, якщо хочете отримувати оновлення із закритим застосунком.

На іншому комп’ютері перше QR-підключення потрібне знову. Для перезапусків того самого сервера зазвичай достатньо автоматичного відновлення або кнопки **Знайти й підключити** / Check & connect. Поточний Android-клієнт використовує одне обране підключення, а не одночасний огляд кількох ПК.

## 5. Мова й віджети

У нижній частині головного екрана Android натисніть **Мова застосунку / App language**. Доступні «Автоматично», «Українська» та English. Автоматично: англійська мова телефона → English; українська або будь-яка інша → українська. Ручний вибір зберігається після перезапуску та оновлення. Підключення телефона зберігається; зміна мови не створює нового звукового сигналу питання чи завершення.

Короткі позначки віджетів Ready, Working, Needs you, Live залишаються англійською. Щоб додати віджет: затисніть вільне місце домашнього екрана → Віджети → Agent Beacon. У **Налаштуваннях віджетів** виберіть конкретну велику картку, 1–3 агентів, їхній порядок і лічильники. Кожна копія налаштовується окремо.

Низький віджет показує рядки без заголовка; вузький — назви й кольорові індикатори. Для повних написів збільшіть ширину, для дуже великого шрифту — висоту. `Working · 3` означає три актуальні чати агента, серед яких є активний. Це не означає, що всі три працюють.

На Samsung можна додати віджет через Good Lock / LockStar. Відображення на екрані блокування залежить від можливостей і дозволів конкретного телефона. Перемикач Live Updates — інша експериментальна функція Android.

## 6. Щоденна робота

Червоний — агент працює. Жовтий — потрібна відповідь або ще чинне нагадування про питання. Зелений — готовий до нового запиту, а не оцінка якості відповіді. Сірий — немає підтвердженого свіжого стану.

Питання й завершення запиту можуть сповіщати звуком і вібрацією. Початок роботи та звичайні оновлення тихі. Готові чати залишають актуальний список через 30 хвилин без активності. «Відстеження чату завершено» не видаляє сам чат.

Закриття вкладки браузера залишає Beacon у треї. Щоб повністю завершити програму, виберіть **Вийти** в треї. Автозапуск Windows — окрема необов’язкова галочка. Якщо протягом 30 хвилин лишається тільки невідомий статус, Android автоматично призупиняє фоновий моніторинг. Відкриття застосунку відновлює моніторинг після цієї автоматичної паузи. Кнопка **Stop** у сповіщенні зупиняє моніторинг вручну; після неї повторне відкриття застосунку не запускає його автоматично.

## Якщо не підключається

- Хуки записані, стан сірий: відкрийте новий локальний чат або перезапустіть агента й дайте справжнє завдання.
- ПК видно, телефон не підключається: перевірте LAN у майстрі, однакову мережу, VPN та ізоляцію гостьового Wi-Fi. Кнопка дозволу в брандмауері окремо запитує адміністратора; вона стосується Beacon у Private/LocalSubnet. Профіль мережі автоматично не змінюється.
- Змінився IP або порт: залиште одну потрібну копію Beacon і натисніть «Знайти й підключити». Програма обходить зайняті порти. Якщо мережа блокує пошук, створіть новий QR.
- Немає сповіщень: перевірте дозволи Agent Beacon, канали, гучність, «Не турбувати» й фонові обмеження Android.
- Після оновлення віджет старий: відкрийте застосунок, перевірте підключення й за потреби вимкніть та ввімкніть фоновий моніторинг. Не очищайте дані.
- ПК спить або вимкнений: він не може передавати актуальний стан.

Для повідомлення про помилку вкажіть версії, агента та кроки відтворення. Не додавайте QR підключення, токени, приватні конфігурації або тексти клієнтських чатів.

## Оновлення, перехід зі старої копії та видалення

Android оновлюйте поверх попередньої версії, без видалення. Windows — новим Setup EXE. Налаштування й підключення зберігаються окремо від програми.

При переході зі старого запуску з папки проєкту закрийте старий Beacon у треї. Майстер може запропонувати перенесення телефонів, якщо знайдено одне впізнане джерело та новий реєстр порожній. Після цього натисніть Check & connect на телефоні. Якщо одночасно працюють дві копії, вони можуть заважати автоматичному пошуку.

Видалення: Налаштування Windows → Програми → Agent Beacon beta або Uninstall-AgentBeacon.exe. Дані телефона залишаються. Окремий вибір прибирає лише впізнані хуки цієї копії. Змінені файли та попередні версії зберігаються; правила firewall автоматично не прибираються.

Це тестова збірка. Чиста Windows, повний ручний прохід інсталятора/UAC/ярликів і фізичні Samsung Home/LockStar ще потребують перевірки. iPhone відкладено.
