# Agent Beacon

**Українська** · [English](README.en.md)

**Знайте, коли AI-агентам потрібна ваша увага.** Локальний індикатор у треї Windows, сповіщення та налаштовувані Android-віджети для Codex і Claude Code, з експериментальною підтримкою Antigravity.

[**Завантажити для Windows — EXE**](https://github.com/Karaoki15/agent-beacon/releases/download/v0.2.0-beta.3/AgentBeacon-Setup.exe) · [**Завантажити для Android — APK**](https://github.com/Karaoki15/agent-beacon/releases/download/v0.2.0-beta.3/AgentBeacon-Android.apk)

Windows **0.2.0-beta.3** · Android **0.1.14** · [Файли релізу та контрольні суми](https://github.com/Karaoki15/agent-beacon/releases/tag/v0.2.0-beta.3)

## Встановити за кілька кроків

Для завантаження й користування **не потрібні Git, Python, GitHub Desktop або акаунт GitHub**.

1. Натисніть **Завантажити для Windows — EXE** вище, збережіть файл і запустіть його на комп’ютері, де працюють агенти.
2. Виберіть **Встановити й відкрити**. Потрібний runtime уже включений.
3. У браузерному майстрі виберіть агентів → **Переглянути зміни** → **Підключити вибраних агентів**. Попередні налаштування резервуються перед додаванням хуків.
4. Перезапустіть агента або відкрийте новий локальний чат і дайте коротке завдання. Перевірте отримання справжньої події.
5. Для Android увімкніть доступ для телефона. Встановіть APK через QR завантаження, потім відскануйте **окремий QR підключення всередині Agent Beacon**. Телефон і ПК мають бути в одній довіреній мережі.

[**Повний покроковий гайд →**](docs/INSTALL_UK.md) · [Проблеми з підключенням та оновлення](docs/INSTALL_UK.md#якщо-не-підключається)

## Що показує Beacon

| Індикатор | Значення |
| --- | --- |
| 🔴 Working | Підключений агент виконує запит. |
| 🟡 Needs you | Потрібна відповідь або ще чинне нагадування про питання. |
| 🟢 Ready | Готовий до наступного запиту. Це не оцінка правильності результату. |
| ⚪ No update | Немає підтвердженого свіжого сигналу. |

- Стан у треї Windows та локальна вебсторінка з назвами чатів і проєктів.
- Android-сповіщення про питання й завершення запиту. Початок роботи та звичайні оновлення тихі.
- Компактний віджет і велика картка агентів. Кожна велика картка має власний вибір агентів, порядок і лічильники.
- Автоматичне відновлення зв’язку, економія батареї та діагностика підключення.
- **Українська / English** у застосунку Android. Автоматично: англійська мова телефона → English; решта мов → українська. Мову також можна вибрати вручну. Короткі позначки віджетів залишаються англійською.

## Агенти й приватність

| Агент | Підтримка в цій беті |
| --- | --- |
| Codex | Підключені локальні сесії через підтримувану інтеграцію хуків/спостерігача. |
| Claude Code | Локальні Code-сесії з увімкненими хуками Beacon. |
| Antigravity | Експериментальний адаптер хуків; потрібна жива перевірка застосунку. |

Звичайний **Claude Chat**, хмарні й SSH/WSL-сесії та iPhone цією бетою не охоплюються. Встановлення Beacon не авторизує вас в агенті й не змінює його дозволів інструментів.

Телефон отримує стан і назви чатів/проєктів замість текстів запитів і відповідей. Beacon працює через ваш комп’ютер і довірену локальну мережу; зовнішній сервер або хмарний акаунт Beacon не потрібні. QR підключення одноразові й чинні дві хвилини — їх не слід публікувати.

## Статус бети

EXE поки **без Authenticode-підпису**, APK — із **debug-сертифікатом розробки**. Windows або Android можуть показувати системні попередження. Перевіряйте джерело й контрольні суми релізу; не вимикайте захист для запуску неперевіреного файла.

Збірки, цілісність пакета, фактичні EXE/helper/tray і програмні перевірки пройдено. Чиста Windows, повний ручний прохід інсталятора/UAC/ярликів та фізичні Android/LockStar ще потребують перевірки. Це бета-перегляд, а не твердження про тестування всіх пристроїв.
